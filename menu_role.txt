# Aturan bisnis

## 1. Booking belum dibayar

User masih boleh:

* membatalkan booking
* membiarkan booking sampai expired

Efek sistem:

* status booking jadi **Cancelled** atau **Expired**
* slot lapangan kembali tersedia

## 2. Booking sudah dibayar

User **tidak bisa membatalkan**
Efek sistem:

* booking tetap aktif
* slot tetap terkunci
* tidak ada refund
* tidak ada saldo internal

# Alur sistem yang benar sekarang

## Alur user

1. User pilih jadwal
2. User buat booking
3. Sistem buat invoice QRIS
4. Jika user bayar:

   * pembayaran = **Paid**
   * booking = **Confirmed**
   * booking tidak bisa dibatalkan
5. Jika user tidak bayar:

   * user bisa klik batal, atau
   * sistem otomatis expired setelah batas waktu habis

## Jika belum dibayar

Tampilkan:

* **Bayar Sekarang**
* **Batalkan**

## Jika sudah dibayar

Tampilkan:

* **Lihat Detail**
* **Lihat Invoice**

Jangan tampilkan tombol batal.

---

# Teks kebijakan yang bisa dipasang di sistem

Kamu bisa pakai kalimat ini:

> Booking yang belum dibayar dapat dibatalkan sebelum batas waktu pembayaran berakhir. Booking yang sudah berhasil dibayar tidak dapat dibatalkan atau diuangkan kembali.

Kalau mau versi yang lebih formal:

> Pembatalan hanya dapat dilakukan pada reservasi dengan status belum dibayar. Reservasi yang telah berhasil dibayarkan melalui sistem tidak dapat dibatalkan dan pembayaran tidak dapat dikembalikan.
