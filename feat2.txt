
#### 1. Member Area (Prioritas Tinggi)

Karena sistem reservasi berpusat pada member.

Menu member:

```text
Home
Jadwal
Booking
Riwayat
Profile
```

Yang menurut saya masih kurang:

```text
✓ Edit Profile
✓ Ubah Password
✓ Download QR Booking
✓ Download PDF Booking
✓ Detail Booking
```

Ini sangat relevan dengan tujuan sistem.

---

#### 2. Home Member

Daripada halaman kosong.

```text
Booking Aktif
```

dan

```text

```

Ini meningkatkan usability.

#### 3. Landing Page Publik

Sangat bagus untuk TA karena menunjukkan sistem tidak hanya untuk internal.

Misalnya:

```text

Daftar Lapangan
Harga
Jadwal Tersedia
Login
Register
```

Bahkan tanpa integrasi QRIS pun sudah bagus.

### Jika saya jadi pembimbing

Saya akan menyarankan roadmap akhir:

```text
1. Selesaikan fitur Member
   - Profile
   - Ubah Password
   - Detail Booking
   - Download QR
   - Download PDF

2. Selesaikan Landing Page

3. Rapikan Dashboard Owner

4. Testing dan Dokumentasi
```

Karena setelah itu sistem reservasi Anda sudah terasa lengkap dari sisi **member → petugas → admin → owner**, yang biasanya menjadi poin kuat saat sidang TA.
