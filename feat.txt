# Struktur Database

Menurut saya tidak perlu tabel baru.
Manfaatkan tabel booking yang sudah ada.

Member:

'user_id' => 15

Non Member:

'user_id' => null

Tetapi:

'nama_pemesan' => 'Budi'
'no_hp_pemesan' => '08123xxxx'

tetap diisi.

---

# Tambahkan Tipe Booking

Anda sudah punya:

BOOKING_TYPE_ONLINE

Tambah:

define(
    'BOOKING_TYPE_WALKIN',
    'walkin'
);

Saat petugas membuat booking:

'tipe_booking'
    =>
    BOOKING_TYPE_WALKIN

---

# Status Otomatis

Karena sudah datang ke lokasi:

Walk In
↓
Bayar
↓
Main

status_booking
=
STATUS_BOOKING_CHECKIN

langsung.

Tidak perlu:

pending
confirmed

---

# Pembayaran Otomatis

Buat record pembayaran:

$pembayaran = [
    'booking_id' => $booking_id,

    'jumlah_bayar' => $total,

    'metode_bayar' => 'cash',

    'status_pembayaran'
        =>
        STATUS_PEMBAYARAN_PAID,

    'paid_at'
        =>
        date('Y-m-d H:i:s')
];

---

# Riwayat Booking

status_booking

checkin
